# AI가 제안한 최적화와 실제 적용 내용

환경: Unity 6000.3.22f1, URP, `GameScene`, 에디터 Play 모드(1920x1080)

## 1. 진행 방식

1. AI에게 CPU / GPU / RAM 관점에서 코드와 에셋을 조사하게 하고(병렬 조사 3건), 최적화 후보를 제안받았다.
2. 정적 조사는 추정이라 **프로파일러 수치로 확정하는 단계**를 따로 두었다. (`PerfCapture` 에디터 도구)
3. 같은 위치에서 설정만 번갈아 바꾸는 A/B 측정으로 효과를 확인했다.
4. 효과가 있는 것만 적용하고, 효과가 없거나 측정으로 근거가 없는 것은 적용하지 않았다.

## 2. 제안과 적용 결과 한눈에 보기

| 영역 | AI가 제안한 방법 | 적용 여부 | 측정 결과 |
| --- | --- | --- | --- |

| GPU | 오클루전 컬링 베이크 | **적용** | 가로등 위치 Draw Call −44%, 삼각형 −97% |

| RAM | 배럴 텍스처 최대 크기 축소 | **적용** | 씬 텍스처 97.8MB → 77.8MB (−20MB) |

## 3. 실제 적용한 최적화

### 3.1 미니맵 카메라: 그림자 끄기 + 렌더 간격
- **제안 근거:** 미니맵 카메라가 메인 카메라와 같은 렌더러로 매 프레임 한 번 더 그리며 그림자 맵까지 만들고 있었다. 미니맵을 끄면 삼각형이 3.10M에서 1.59M(−49%)로 줄었다.
- **변경 내용**
  - 씬: `MinimapCamera`의 Render Shadows를 끔.
  - 코드(`MinimapCamera.cs`): `_renderInterval`(기본 3)프레임마다 `Camera.Render()`로 직접 렌더. 1 이하이면 기존처럼 자동 렌더. 줌을 바꾸면 즉시 다시 그림.
- **측정 (V3, timeScale 0)**

| 설정 | 프레임(ms) | Draw Calls | SetPass | 삼각형 |
| --- | ---: | ---: | ---: | ---: |
| 원본 | 12.5 | 550 | 73 | 3.09M |
| 그림자만 끔 | 11.6~12.2 | 528 | 70 | 2.58M |
| 간격 3 + 그림자 끔 (적용) | 10.5 | 482 | 60 | 1.91M |
| 간격 6 + 그림자 끔 | 10.0~11.1 | 469 | 57 | 1.72M |

- 간격 6은 조금 더 줄지만 갱신이 끊겨 보일 수 있어 3을 선택했다.

### 3.2 오클루전 컬링 베이크
- **제안 근거:** 정적 오브젝트 402개가 Occluder/Occludee Static이었지만 베이크 데이터가 없어 오클루전 컬링이 동작하지 않았다.
- **변경 내용:** 기본 설정(가장 작은 가림막 5m, 가장 작은 구멍 0.25m)으로 베이크. `OcclusionCullingData.asset`(226KB) 추가.
- **측정 (같은 세션, 켬/끔)**

| 위치 | Draw Calls | 삼각형 |
| --- | --- | --- |
| V1 | 168 → 156 (−7%) | 2.03M → 2.03M |
| V3 | 459 → 405 (−12%) | 1.59M → 1.58M |
| 가로등 | 356 → 199 (−44%) | 1.06M → 0.03M (−97%) |

- 그리는 양은 줄었지만 에디터 프레임 시간 개선은 뚜렷하지 않았다.

### 3.3 URP Opaque Texture 끄기
- **변경 내용:** `PC_RPAsset`의 Opaque Texture를 끔. 프로젝트 셰이더 중 `_CameraOpaqueTexture`를 쓰는 것이 없어 화면 변화가 없다.
- **측정 (V3):** Draw Call 556 → 553, SetPass 73 → 70.

### 3.4 배럴 텍스처 크기 축소
- **변경 내용:** 씬이 쓰는 텍스처 42개(97.8MB) 중 가장 큰 3장의 Max Size를 2048 → 1024로 낮춤.

| 텍스처 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| BarrelBiohazard_MetallicSmoothness | 10.7MB | 2.7MB |
| BarrelMilitary_Normal | 10.7MB | 2.7MB |
| BarrelMilitary_AlbedoTransparency | 5.4MB | 1.4MB |
| **씬 텍스처 합계** | **97.8MB** | **77.8MB** |

## 4. 적용하지 않은 제안과 이유

| 제안 | 측정 결과 | 결정 |
| --- | --- | --- |
| 좀비 `SetDestination` 주기 제한 | `Crowd.Pathfinding` 0.02ms (프레임의 0.1%) | 적용 안 함 |
| `Idle`/`Attack`의 매 프레임 `StopAgent()` 제거 | 스크립트 전체 `Update` 0.23ms | 적용 안 함 |
| `Vector3.Distance` → `sqrMagnitude` | 결과 동일, 비용 미미 | 적용 안 함 |
| `UI_PlayerStats` 문자열 할당 제거 | 프레임당 할당 중앙값 약 18KB는 대부분 에디터 기준값 | 적용 안 함 |
| 소프트 섀도 High → Medium | Draw Call·삼각형 변화 없음 | 적용 안 함 |
| Bloom High Quality Filtering 끄기 | 변화 없음 | 적용 안 함 |
| 미니맵 Far Clip 1000 → 50 | Draw Call·삼각형 변화 없음 | 적용 안 함 |
| 작은 소품 그림자 끄기 | 대상 20개, 그림자 캐스터 −5 | 적용 안 함 |
| `Sword`, `Finn` 에셋 정리 | 씬이 텍스처를 실제로 참조함 | 정리 불가 |

## 5. AI 제안이 틀렸던 부분

정적 조사만으로 제안했던 내용 중 측정이나 확인 단계에서 틀린 것으로 드러난 부분이다.

| AI의 초기 판단 | 실제 |
| --- | --- |
| `Sword`, `Finn` 에셋은 미사용 | 씬이 텍스처를 실제로 참조하고 있음 |
| 혈흔·폭탄 이펙트는 `Instantiate` 사용 | 코드는 이미 풀링을 사용하고 있음 |
| APV 데이터가 약 150MB | 라이트맵까지 합친 값이었음 |
